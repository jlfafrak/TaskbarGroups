# Preserve Alt+Tab for grouped windows

**Goal:** Keep identifiable grouped windows in Alt+Tab while combining their taskbar buttons.

**Approach:** Replace new `DeleteTab` operations with a window-level AppUserModelID matching the group, recording the prior property and the intended group in the recovery journal before modifying the window. Restore legacy DeleteTab records with AddTab. Only recover identity properties still owned by this session and marked on the same process/window. Window matching recognizes journaled windows after reassignment without accepting unrelated explicit identities.

**Checks:** Test journal backwards compatibility and restoration policy, window matching, preference changes, watcher crash recovery, multiple windows and Alt+Tab with disposable windows. Verify group hover and click behavior, existing installer upgrades, Rust checks, and a fresh MSI before updating the installed application.
